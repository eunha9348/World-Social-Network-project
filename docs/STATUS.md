## VMAX 업데이트
별자리 메뉴와 확대 전환, 블랙/블루/화이트 테마, 개인 프로필·보고서·참여 토론 마이페이지 추가. 공개 운영 설명 및 연결 상태 제거. 개인 프로필 migration은 0001에 추가하며 기존 0000 보존. 상세 비용·키 발급은 OWNER_REPORT.md에만 수록.

97개 출처 후보 목록·주요 언어 필터·작성자 근거 필드를 추가했다. 반입은 필터 목록 외 BCP-47 원문 코드도 수용한다. 0002 migration에 작성자 메타데이터를 추가했다. 기본 보고서/비교는 원문 발췌이며 AI 인용/종료 발췌는 정확한 문자열 일치를 검증한다. 실제 연결은 HN 수집기와 JSONL 경로뿐이고 원문 corpus는 여전히 0건이다.

이번 수정 검증: TypeScript 검사, 배포 빌드, Python 5개 테스트, 가짜 인용 거부/출처 정렬/작성자 다양성 검증, SQLite 전체 migration 적용을 통과했다. 유료 AI 및 브라우저 통합 검증은 미실행이다.

UI 조정: 별자리 시작 화면은 유지하고 기능 화면에 이전 대시보드형 좌측 탐색과 범용 언어 검색 상태를 결합했다. 모바일에서는 좌측 메뉴 대신 하단 빠른 메뉴를 사용한다.

다국어 구조 개편: 언어별 고정 수량 목표와 별도 언어 RAG 표시를 제거했다. 원문 1회 저장·공통 다국어 임베딩·현재 표시 결과만 LLM 번역·원문 해시 기반 D1 캐시 구조로 전환했다. 선택 비교도 별도 번역 corpus 없이 원문을 직접 읽고 UI 언어로 분석하며 인용은 원문 문자열 일치를 검증한다.

2026-09-18 최종 인수 검증: ESLint 0건, TypeScript `--noEmit`, Python 5개 테스트, Vinext 프로덕션 빌드를 통과했다. 빈 SQLite DB에 `0000`–`0003` migration을 순서대로 적용해 9개 운영 테이블 생성을 확인했다. OpenAI·Qdrant 비밀키와 승인된 실제 corpus가 없으므로 유료 API 통합과 실제 검색 품질은 아직 검증하지 않았다. GitHub 인수 순서는 `docs/GITHUB_HANDOFF.md`에 고정했다.

UI 재조정: 별자리·혼합형 화면을 제거하고 초기 좌측 메뉴형 리서치 대시보드로 복원했다. Apple 한국어 시스템 글꼴 우선 순위, 중앙 정렬형 콘텐츠 폭, 겹침 방지 반응형 규칙, 저장되는 라이트·다크 모드를 추가했다.

랜딩 페이지: 제품 소개와 워크스페이스를 분리하고 Spotlight, Background Beams, Bento Grid, Moving Border 계열의 상호작용을 VMAX 콘텐츠에 맞춰 구현했다. 후보 디렉터리 수와 실제 연동을 혼동하지 않도록 랜딩에도 구분 문구를 표시한다.

지구형 랜딩 개편: 고해상도 WebGL 점군 지구, 기울어진 자전축, 회전값에 동기화된 국가별 커뮤니티 라벨, 드래그 회전, 스크롤 시 지구 이동·축소와 3단계 설명 전환을 구현했다. 랜딩 전체 문구는 한국어·영어를 지원하며 선택을 브라우저에 저장한다. 한국어는 어절 유지 줄바꿈과 별도 문장 길이를 적용했다.
