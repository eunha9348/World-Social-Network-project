# 출시 점검

작성: 2026-09-21 · 기준: 배포 버전 24, corpus 40건(ko 20 / en 20)

수집·판별·임베딩·저장 경로는 실데이터로 완주했다. 남은 것은 **사용자가 실제로 만지는 화면**이다.

---

## 1단계. AI 기능 점검 (지금 · 30분 · 비용 극소)

공급자를 OpenAI에서 Gemini로 바꾼 뒤 **아래 6개 경로는 한 번도 실행된 적이 없다.**
`ai()`가 JSON 계약을 못 지키면 전부 502로 떨어진다. 배포 전에 반드시 직접 눌러본다.

관리자 계정으로 로그인한 상태에서 순서대로 확인한다.

- [ ] **검색** — 한국어로 검색. 응답의 `mode`가 `hybrid-rrf`인가?
      `lexical`이면 벡터 경로가 죽은 것이다. 화면의 경고 문구를 그대로 기록한다.
- [ ] **재순위화** — 검색 옵션에서 재순위화를 켜고 다시 검색. 502가 아닌가?
- [ ] **요청 시 번역** — 한국어 결과를 영어로, 영어 결과를 한국어로 번역.
      같은 결과를 다시 번역할 때 즉시 나오는가? (D1 캐시 적중 = 재과금 없음)
- [ ] **의견 비교** — 게시글 2개 이상 선택 후 비교. 감성과 주장이 분리되어 나오는가?
- [ ] **보고서** — 1페이지로 생성. 본문이 원문 발췌인가?
      (이 경로는 LLM을 쓰지 않으므로 실패하면 데이터 문제다)
- [ ] **토론방 개설** — 보고서에서 공개 토론 개설. `moderate()`가 통과시키는가?
- [ ] **AI 토론 2역할** — 분석가·반론 검토자 발언 생성. 실제 게시글 ID를 인용하는가?
- [ ] **발언 전송** — 평범한 문장을 전송. 통과하는가?
- [ ] **유해 발언 차단** — 인신공격성 문장을 전송. **차단되는가?**
      통과되면 즉시 멈추고 원인을 찾는다. 이것은 안전 장치다.
- [ ] **종료·요약** — 방 종료 후 요약 보고서 생성.
- [ ] **음성 입력** — 마이크 버튼 → 초안 확인 → 전송 (브라우저 지원 시)
- [ ] **마이페이지** — 프로필 저장 후 새로고침. 유지되는가?

**하나라도 502가 나면** 그 화면의 오류 문구와 무엇을 눌렀는지를 기록한다.
`ai()`는 토큰 한도 초과를 "잘렸습니다"로, 형식 오류를 "형식이 올바르지 않습니다"로
구분해서 보고하므로 문구가 곧 원인이다.

## 2단계. corpus 확대

**40건으로는 대부분의 검색이 빈손이다.** 사용자가 처음 만나는 인상이 "결과 없음"이면
나머지 기능이 아무리 좋아도 의미가 없다. 이것이 지금 가장 큰 제품 결함이다.

- [ ] 1단계가 통과하면 `SCHEDULE_ENABLED=true`로 일일 자동 수집을 켠다
- [ ] `SCHEDULE_MAX_DOCUMENTS`로 하루 비용 상한을 정한다 (기본 40)
- [ ] 매일 아티팩트를 `/admin/ingest`에 올린다
- [ ] 2주 뒤 언어·출처 분포를 확인하고 `pipeline/sources.json`의 그룹 예산을 조정한다

일일 40건이면 2주에 약 560건, 한 달에 약 1,200건이다.
언어별로는 9개 그룹에 나뉘므로 한 언어당 하루 약 4건이다. **느리다.**
더 빠르게 하려면 `SCHEDULE_PER_GROUP`과 `SCHEDULE_MAX_DOCUMENTS`를 올리되,
모델 비용이 그만큼 비례해 늘어난다는 점을 먼저 계산한다.

## 3단계. 수동 업로드 제거 (전략적 결정)

ChatGPT Sites는 서버 간 호출을 403으로 막으므로 수집기가 DB에 직접 쓸 수 없다.
지금 구조는 **매일 사람이 파일 하나를 올려야** 완성된다. 선택지는 둘이다.

| | 유지 | 이전 |
|---|---|---|
| 작업 | 없음 | 인증 재구현 + 배포 이전 |
| 일상 | 매일 수동 업로드 1회 | 없음 |
| 확장 | 사람이 상한 | 무인 |
| 문서 | — | `docs/DEPLOY_VERCEL_SUPABASE.md` |

corpus가 수백 건 수준이고 하루 한 번이 견딜 만하면 유지해도 된다.
수천 건 규모나 실사용자를 받을 계획이면 이전이 전제 조건이다.

## 4단계. 실사용자를 받기 전 필수

아직 하나도 검증되지 않았다.

- [ ] **다중 사용자 격리** — 서로 다른 계정 2개로 로그인해 상대의 보고서·프로필이
      보이지 않는지, 공개 토론만 공유되는지 확인
- [ ] **사용량 한도** — 시간당 한도가 실제로 429를 반환하는지 확인
      (발언 60, 보고서 10, 비교 15, 토론 12, 의미 검색 60, 재순위화 30)
- [ ] **비용 상한** — Google Cloud 예산 알림은 호출을 끊지 않는다.
      Cloudflare AI Gateway의 rate limit으로 실제 차단을 건다
- [ ] **삭제 전파** — 원문 삭제 시 D1·Qdrant·기존 보고서 스냅샷까지 처리.
      **자동 전파는 아직 구현되지 않았다**
- [ ] **백업** — D1 일일 백업과 Qdrant snapshot 정책. 복원을 한 번 해본다
- [ ] **검색 품질 평가** — 언어별 평가 질의로 `pipeline/evaluate.py` 실행.
      실패 사례를 모아 부족한 주제·언어의 corpus를 우선 보강
- [ ] **모더레이션 오탐** — 언어별로 정상 발언이 차단되지 않는지 검토
- [ ] **운영자 연락처·이의 접수 경로** 지정

## 아직 사실이 아닌 것

홍보 문구를 쓰기 전에 확인한다.

- corpus 40건은 서비스가 아니라 시연이다
- 97개 출처 중 실제 수집 중인 것은 6개 제품군(호스트 54개)이다
- 할루시네이션 0%는 보장할 수 없다. 원문 링크·인용 일치·불확실성 표시로 낮출 뿐이다
- 현재 음성은 브라우저 인식 기반 턴 방식이며 동시 오디오 회의가 아니다
- 네이버·디시인사이드·클리앙 등은 수집하지 않으며 이용 권한 확보 전까지 계획이 없다
